Bring your own agent

The tools you already pay for.

Centcom drives your installed Claude Code and Codex. It never asks for, stores or sees a password or API key. If your CLI is signed in, Centcom works. If it is not, Centcom tells you which command to run.

See it, then approve it

Every change is a diff you can read.

Edits and commands arrive as a card with the exact diff, a risk label, and a clear Allow or Decline. Destructive commands need a second confirmation. You choose how strict to be, per session.

Many hands Planned

One session, the whole team.

Two machines on the same Wi-Fi share a session with no account and no server. A hosted relay will do the same across the internet, end-to-end encrypted. Each person's agent runs on their own account.

Ship it

Tests green. Commit when you are ready.

Cento reacts to what the agent is really doing: thinking, reading, running, waiting for you, done. You can tell at a glance across a room, or turn the animation off entirely.

How it works

Centcom stands next to your CLI, not in front of it.

1. You sign in once, the usual way

claude auth login or codex login. Centcom only checks the status the CLI reports.

2. Centcom starts the CLI for you

It speaks each tool's documented machine interface and turns the stream into one set of events: text, tool calls, diffs, approvals, usage.

3. You see and steer everything

Approve, interrupt, switch model, or hand the same session to the web app. Model usage is billed to your own provider account, as before.

FAQ

Straight answers.

Does Centcom use my Claude or ChatGPT subscription?

It uses whatever your own installed CLI is signed in with. Centcom starts the CLI and never touches your credentials. Whether a shared or team setup is permitted under your provider's terms is your provider's call, so we default to the safe behavior and plan to get written confirmation before enabling shared subscription use.

Is Centcom affiliated with Anthropic or OpenAI?

No. It is an independent project by Caffeine Driven. Claude, Claude Code, Codex and OpenAI are trademarks of their owners.

Can I try it today?

Yes, from source. Clone the repository, run pnpm install, then pnpm dev for a scripted demo or pnpm centcom for your real agent. There is no packaged installer yet.

Is the multiplayer part real yet?

Not yet. The protocol, encryption and billing contracts are written and frozen, and the build plan is public. LAN and hosted sessions are the next big milestone, and the page above shows exactly how far along they are.

What does "dangerously skip permissions" do?

It turns off every approval. Cento runs commands and edits files immediately, including destructive ones. It is for sandboxes and throwaway projects. Centcom asks you to confirm, shows a red banner while it is on, and switches back with one click.

Does it work on Windows or macOS?

It is built and tested on Linux. The code is plain Node and should run elsewhere, but we have not tested those platforms and will not claim support before we have.

Who makes Centcom?

Caffeine Driven LLC. Lead developer Alexander Gese (@AlexanderGese). Our work lives at github.com/Caffeine-Driven-LLC.
